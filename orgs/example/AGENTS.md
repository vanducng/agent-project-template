# Example org

A synthetic org that shows the layout. Copy it to `orgs/<your org>/`, then rename and fill it in.

- GitHub owner `example-org`. Route work by owner, not by folder name.
- Repos and their paths per machine: `repos.yaml` in this folder.
- Default machine: `laptop`.

## Rules and what enforces them

| Rule | Enforced by | Detail |
|---|---|---|
| PRs open as drafts. Merge, deploy, and messages to people need the operator's explicit word. | prose only | - |
